# Uvic CSC 370, Fall 2026
## Project: Movie Rating System

This project is a movie rating database built using MySQL. It allows users to rate and review movies while storing information about movies, genres, actors, directors, and production studios.

The database consists of 11 tables connected through primary and foreign keys. It uses SQL queries to retrieve movie information, manage user ratings, and calculate average ratings. Constraints are used to maintain data integrity and manage relationships between tables.
